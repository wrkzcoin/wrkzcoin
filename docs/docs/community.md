## Where to take what

**Discord** is the fastest route for anything operational — a node that will
not start, a wallet that will not sync, a question about which flags to use.
Bring the daemon log and the exact command line; both matter more than the
description of the symptom.

**GitHub issues** are for reproducible bugs and feature requests against
[wrkzcoin/wrkzcoin](https://github.com/wrkzcoin/wrkzcoin/issues). Use the issue
templates: they ask for the version string (`Wrkzd --version`), the platform,
and the steps, which is what makes an issue actionable.

**X** carries release announcements and network notices, including fork
heights. It is a broadcast channel, not a support channel.

## Contributing

Pull requests go to the `development` branch of
[wrkzcoin/wrkzcoin](https://github.com/wrkzcoin/wrkzcoin). Build instructions
are in `COMPILE.md`. The repository's `README.md` has a note for contributing
developers about license headers: any open source project may use this software,
but the license headers may only be appended to, never altered.

Documentation lives in `docs/` in the same repository, and every page on this
site has an edit link in its top-right corner that opens the source file on
GitHub.

## Security reports

Do not open a public issue for a vulnerability that affects funds, consensus or
node availability. Report it privately to a maintainer on Discord first, so a
fix can be released before the detail is public.
